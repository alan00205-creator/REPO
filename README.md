# 緊落來！台灣人下樓梯

遊戲名稱「緊落來」是台語「快下來」的意思，就是台灣媽媽喊小孩「緊落來食飯！」的那句。

致敬 1996 年 Nagi-P Soft 的經典遊戲《NS-SHAFT》（台灣俗稱《小朋友下樓梯》）的瀏覽器小遊戲。
天花板的刺一路往下追，你要控制主角一階一階往下跳，看能撐到地下幾階。主角可以換上各種台灣味造型，從戴礦工帽的阿燈到 8+9 台客、里長伯都有。

整個遊戲只有一個檔案 `index.html`，用電腦或手機的瀏覽器直接打開就能玩，不需要安裝。

## 玩法

- 主角只能左右移動，會自己往下掉。踩到台階就站住，畫面會一直往下捲。
- 頭撞到上方的刺，或掉出畫面下方，都會受傷或出局。
- 生命共 12 格：撞到天花板扣 5 格、踩到釘板扣 5 格，踩到沒踩過的台階回 1 格。
- 越往下捲動越快，台階種類也越多。

| 台階 | 效果 |
|---|---|
| 石板 | 穩穩的，放心踩 |
| 碎石板 | 踩上去一下子就碎掉 |
| 彈簧 | 把你彈起來（離天花板太近時不會彈） |
| 輸送帶 | 把你往左或往右送 |
| 釘板 | 有刺，踩到扣血 |

## 操作

| 裝置 | 移動 | 其他 |
|---|---|---|
| 手機／平板 | 按住畫面左半邊往左、右半邊往右 | 右上角按鈕暫停 |
| 鍵盤 | ← → 或 A D | Esc 或 P 暫停、M 靜音、結算畫面按 Enter 或 R 再玩一次 |
| 鍵盤（雙人） | 1P：A D　2P：← → | 同上 |

## 內容

- **單人／雙人**：用電腦玩時，標題畫面可以切換「單人」或「雙人」。雙人時 1P 用 A D、2P 用 ← → 移動，兩人在同一個豎井裡往下跳，身體碰到會互相推擠（可以把對方推下台階）。一人出局後另一人繼續，兩人都出局才結算，下得比較深的獲勝；同樣深度時撐得比較久的獲勝。最佳紀錄和造型解鎖以兩人中較深的為準。手機只提供單人模式。
- **台灣地底巡禮**：背景會隨深度換場景，依序是夜市老街（B0）、地下街（B50）、捷運站（B100）、北投地熱谷（B200）、地心（B300，有一頭沉睡的地牛）。場景中沒有任何真實的店名、站名或商標。

- **排行榜**：標題畫面的「排行榜」按鈕，單人、雙人分開排名，可以填自己的暱稱（雙人可以分別填 1P、2P）。
  - **這台裝置**：每場打完自動記錄，保留前 10 名。只存在這個瀏覽器裡，換手機或清除瀏覽器資料就會不見；設定裡的「清除紀錄」也會一起清掉。
  - **大家（共用）**：只有在 Claude 預覽頁（claude.ai 的 Artifact）開啟時才會出現，GitHub Pages 版沒有。每人只保留自己最好的一筆。要上榜的人必須被分享為「可參與（Contributor）」以上的權限，只有「檢視」權限的人只能看榜、不能上榜。分數是由瀏覽器自己回報的，懂技術的人有辦法改分數，所以只適合朋友之間娛樂比較。

（前三場，或第一次抵達地下 16 階為止）：台階比較寬、捲動比較慢，第一次出現各種台階時會顯示說明文字；在你第一次按方向（或操作提示顯示完）之前，天花板不會開始往下。

## 網址參數（開發測試用）

| 參數 | 用途 |
|---|---|
| `?seed=數字` | 固定關卡亂數種子，每次都產生相同的台階配置 |
| `?bot=perfect` / `decent` / `novice` | 讓電腦自動遊玩，用來觀察難度 |
| `?debug=1` | 顯示除錯資訊 |
