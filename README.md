# 冰火亂鬥 ICE & FIRE BRAWL

致敬《小朋友齊打交二》（Little Fighter 2）的同人格鬥小品。整個遊戲只有一個檔案 `index.html`，用瀏覽器打開就能玩，電腦和手機都支援。

> 非官方致敬作品。角色、畫面、音樂、音效全部由程式即時繪製與合成，沒有使用原作的圖檔或音檔。

## 怎麼開始

- **電腦**：直接用 Chrome／Edge／Safari／Firefox 打開 `index.html`。
- **手機**：把 `index.html` 放到任何能提供網頁的地方（例如 GitHub Pages），用手機瀏覽器打開；建議橫向遊玩。
- 第一次點擊畫面或按鍵後才會開始播放音樂（瀏覽器規定）。

## 遊戲模式

| 模式 | 內容 |
| --- | --- |
| 對戰模式 | 最多 4 個位置，每格可選「玩家1／玩家2／手把／電腦／未加入」，可分隊。單挑電腦、雙人同機、四人混戰都在這裡。 |
| 闖關模式 | 三關連戰：竹林道場 → 雪原 → 火山口，最後擊敗頭目「闇．焰霜」。鍵盤可開 2P 協力。 |

## 角色

| 角色 | 致敬對象 | 大絕招（防 ↑ 跳） |
| --- | --- | --- |
| 焰霜 | 冰火人 | 冰火天墜：升空施法，冰火隕石落滿全場 |
| 鋼鎧 EX | Louis EX | 赤凰掌：推出貫穿整條直線的火鳳凰（被動「鋼鎧」可硬吃輕攻擊） |
| 凜冬 | 深雪 | 千里冰封：冰龍捲把敵人吸進去連續攻擊，最後全部冰封 |
| 阿烈 | Davis | 百裂拳：霸體前進狂打十六拳，最後一拳轟飛 |

每個角色另有兩招：`防 → 攻`（技一）、`防 ↓ 攻`（技二）。詳細說明在遊戲內「招式表」。

## 操作

| | 1P 鍵盤 | 2P 鍵盤 | 手機 | 手把 |
| --- | --- | --- | --- | --- |
| 移動 | W A S D | 方向鍵 | 左半邊拖曳搖桿 | 左搖桿／十字鍵 |
| 攻・跳・防 | J K L（雙人時也可用 F G H） | 數字鍵 1 2 3，或 , . / | 右側「攻／跳／防」 | X・A・B |
| 放招快捷 | U I O | 數字鍵 4 5 6 | 右側「技／絕」按鈕 | Y・LB・RB |
| 暫停 | Esc 或 P | Esc 或 P | 畫面上方暫停鈕 | Start |

搓招跟原作一樣：先按「防」，再按方向，最後按「攻」或「跳」，三個鍵約半秒內按完。

其他共通動作：攻擊連按三下是連續技、方向鍵快按兩下奔跑、被打飛時在空中按跳可以受身、站在牛奶（補血）或汽水（補氣）上按攻擊可以喝、被冰凍時連打任意鍵脫困。

## 檔案說明

- `index.html`：遊戲本體（HTML＋CSS＋JavaScript 全部在同一檔）。唯一的外部資源是 Google Fonts 字型；離線時會自動改用系統字型，遊戲照常運作。
- 設定（音量、難度、上次選的角色）存在瀏覽器的 localStorage（瀏覽器內建的小型本機儲存空間），只影響你自己的瀏覽器。
