# 台灣人下樓梯（TAIWAN DOWNSTAIRS）

致敬 1996 年 Nagi-P Soft 的經典遊戲《NS-SHAFT》（台灣俗稱《小朋友下樓梯》）的瀏覽器小遊戲。
天花板的刺一路往下追，你要控制主角一階一階往下跳，看能撐到地下幾階。主角可以換上各種台灣味造型，從戴礦工帽的阿燈到 8+9 台客、里長伯都有。

整個遊戲只有一個檔案 `index.html`，用電腦或手機的瀏覽器直接打開就能玩，不需要安裝。

## 玩法

- 主角只能左右移動，會自己往下掉。踩到台階就站住，畫面會一直往下捲。
- 頭撞到上方的刺，或掉出畫面下方，都會受傷或出局。
- 生命共 12 格：撞到天花板扣 5 格、踩到釘板扣 5 格，踩到沒踩過的台階回 1 格。
- 越往下捲動越快，台階種類也越多。

| 台階 | 效果 |
|---|---|
| 石板 | 穩穩的，放心踩 |
| 碎石板 | 踩上去一下子就碎掉 |
| 彈簧 | 把你彈起來（離天花板太近時不會彈） |
| 輸送帶 | 把你往左或往右送 |
| 釘板 | 有刺，踩到扣血 |

## 操作

| 裝置 | 移動 | 其他 |
|---|---|---|
| 手機／平板 | 按住畫面左半邊往左、右半邊往右 | 右上角按鈕暫停 |
| 鍵盤 | ← → 或 A D | Esc 或 P 暫停、M 靜音、結算畫面按 Enter 或 R 再玩一次 |

## 內容

- **新手期**（前三場，或第一次抵達地下 16 階為止）：台階比較寬、捲動比較慢，第一次出現各種台階時會顯示說明文字；在你第一次按方向（或操作提示顯示完）之前，天花板不會開始往下。
- **造型**：共 11 款，依抵達的最深階數解鎖，在標題畫面的「造型」按鈕更換。

  | 解鎖 | 造型 | 特色 |
  |---|---|---|
  | 一開始 | 阿燈 | 黃色礦工帽、藍色吊帶褲 |
  | 地下 10 階 | 早餐店阿姨 | 捲髮包頭巾、圍裙，一手鍋鏟一手大冰奶 |
  | 地下 25 階 | 斗笠 | 竹編斗笠配花布、白色雨鞋 |
  | 地下 50 階 | 機車族 | 安全帽、口罩、袖套、輕便雨衣（掉落時會鼓成降落傘） |
  | 地下 75 階 | 橘貓 | 貓耳頭套、捲捲的尾巴 |
  | 地下 100 階 | 里長伯 | 紅帽、背心、八字鬍，拿大聲公廣播「各位里民」 |
  | 地下 150 階 | 阿嬤怕你冷 | 毛帽、圍巾、厚到手放不下來的鋪棉外套 |
  | 地下 200 階 | 八加九 | 染色飛機頭、墨鏡、白背心、金項鍊、藍白拖 |
  | 地下 300 階 | 舞獅 | 舞獅頭與披風，移動時灑彩紙 |
  | 地下 400 階 | 凍蒜候選人 | 競選帽、當選彩帶和大紅花，移動時灑鞭炮紙屑 |
  | 地下 500 階 | 天燈 | 頭頂一盞天燈，移動時飄火星 |

  所有造型都是「台灣人都認得的角色類型」，不是任何真實人物，也不使用政黨代表色、品牌或標誌。

## 檔案

| 檔案 | 說明 |

## 網址參數（開發測試用）

| 參數 | 用途 |
|---|---|
| `?seed=數字` | 固定關卡亂數種子，每次都產生相同的台階配置 |
| `?bot=perfect` / `decent` / `novice` | 讓電腦自動遊玩，用來觀察難度 |
| `?debug=1` | 顯示除錯資訊 |
