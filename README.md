# 阿燈下樓去（LAMP KID GOES DOWN）

致敬 1996 年 Nagi-P Soft 的經典遊戲《NS-SHAFT》（台灣俗稱《小朋友下樓梯》）的瀏覽器小遊戲。
天花板的刺一路往下追，你要控制戴礦工帽的阿燈一階一階往下跳，看能撐到地下幾階。

整個遊戲只有一個檔案 `index.html`，用電腦或手機的瀏覽器直接打開就能玩，不需要安裝。

## 玩法

- 阿燈只能左右移動，會自己往下掉。踩到台階就站住，畫面會一直往下捲。
- 頭撞到上方的刺，或掉出畫面下方，都會受傷或出局。
- 生命共 12 格：撞到天花板扣 5 格、踩到釘板扣 5 格，踩到沒踩過的台階回 1 格。
- 越往下捲動越快，台階種類也越多。

| 台階 | 效果 |
|---|---|
| 石板 | 穩穩的，放心踩 |
| 碎石板 | 踩上去一下子就碎掉 |
| 彈簧 | 把你彈起來（離天花板太近時不會彈） |
| 輸送帶 | 把你往左或往右送 |
| 釘板 | 有刺，踩到扣血 |

## 操作

| 裝置 | 移動 | 其他 |
|---|---|---|
| 手機／平板 | 按住畫面左半邊往左、右半邊往右 | 右上角按鈕暫停 |
| 鍵盤 | ← → 或 A D | Esc 或 P 暫停、M 靜音、結算畫面按 Enter 或 R 再玩一次 |

## 內容

- **新手期**（前三場，或第一次抵達地下 16 階為止）：台階比較寬、捲動比較慢，第一次出現各種台階時會顯示說明文字；在你第一次按方向（或操作提示顯示完）之前，天花板不會開始往下。
- **造型**：共 10 款，依抵達的最深階數解鎖，在標題畫面的「造型」按鈕更換。

  | 解鎖 | 造型 | 特色 |
  |---|---|---|
  | 一開始 | 阿燈 | 黃色礦工帽、藍色吊帶褲 |
  | 地下 10 階 | 螢光菇 | 會發光的紫色蘑菇帽 |
  | 地下 25 階 | 斗笠 | 竹編斗笠配花布、白色雨鞋 |
  | 地下 50 階 | 番茄 | 紅色吊帶褲 |
  | 地下 75 階 | 橘貓 | 貓耳頭套、捲捲的尾巴 |
  | 地下 100 階 | 夜光 | 綠色吊帶褲、薄荷色頭燈 |
  | 地下 150 階 | 恐龍化石 | 恐龍頭骨帽、骨架睡衣、骨頭尾巴 |
  | 地下 200 階 | 潛水員 | 銅色潛水頭盔，移動時冒泡泡 |
  | 地下 300 階 | 舞獅 | 舞獅頭與披風，移動時灑彩紙 |
  | 地下 500 階 | 天燈 | 頭頂一盞天燈，移動時飄火星 |
- **紀錄**：最佳階數、百階最快時間、遊玩次數會存在瀏覽器裡（`localStorage`，即瀏覽器內建的小型儲存空間）。換瀏覽器或清除網站資料就會不見。
- **標題畫面**會播放事先錄好的示範遊玩。
- **聲音**：音樂與音效全部由程式即時合成，沒有音檔。設定裡可分別開關。
- **減少動態效果**：預設跟隨系統設定，也可以在設定裡手動開或關，會關掉畫面震動、翻轉和彩帶，並減弱閃光。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 完整遊戲（HTML + CSS + JavaScript 都在同一個檔案裡） |
| `README.md` | 本說明 |

唯一的外部資源是 Google Fonts 的兩套字型（粉圓體 Huninn、Bungee）。字型載入失敗或超過 1.2 秒時會改用系統字型，遊戲照常可玩。

## 網址參數（開發測試用）

| 參數 | 用途 |
|---|---|
| `?seed=數字` | 固定關卡亂數種子，每次都產生相同的台階配置 |
| `?bot=perfect` / `decent` / `novice` | 讓電腦自動遊玩，用來觀察難度 |
| `?debug=1` | 顯示除錯資訊 |
