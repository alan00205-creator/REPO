# 豆豆大闖關（BEAN RUSH!）

致敬《Fall Guys》（台灣俗稱「糖豆人」）的瀏覽器 3D 派對闖關遊戲。30 位豆豆一起上場，每回合淘汰一部分人，撐過四個回合、在決賽站到最後的就能拿到皇冠。

整個遊戲打包成單一檔案 `index.html`，用電腦或手機的瀏覽器直接打開就能玩，不需要安裝。

## 怎麼開始玩

- **直接打開**：下載 `bean-rush/index.html`，用瀏覽器開啟。
- **放上網站**：若倉庫開啟了 GitHub Pages（白話：GitHub 提供的免費網頁空間），網址會是 `https://<帳號>.github.io/<倉庫名稱>/bean-rush/`。
- **加到手機主畫面**：用網址開啟後，在 Safari 選「分享 → 加入主畫面」，或在 Android Chrome 選「安裝應用程式／加到主畫面」，之後就能像 App 一樣全螢幕開啟（這個功能需要透過網址開啟，直接開檔案時不會出現）。
- 建議使用最新版的 Chrome、Safari、Edge 或 Firefox。需要瀏覽器支援 WebGL 2（白話：讓網頁能畫 3D 畫面的功能），iPhone 需 iOS 15 以上，近幾年的 Android 手機和電腦都有。

## 操作

| 裝置 | 移動 | 跳 | 飛撲 | 轉鏡頭 | 暫停 |
|---|---|---|---|---|---|
| 手機／平板 | 按住畫面左半邊拖曳（浮動搖桿） | 右下黃色按鈕 | 右下藍色按鈕 | 在畫面右半邊滑動 | 右上角按鈕 |
| 電腦鍵盤滑鼠 | `W` `A` `S` `D` 或方向鍵 | 空白鍵 | `Shift` 或 `E` | 按住滑鼠拖曳，或 `Q` `R` | `Esc` 或 `P` |
| 手把 | 左搖桿 | A | B／X | 右搖桿 | Start |

手機橫拿、直拿都能玩，橫拿視野比較大。鏡頭不碰的時候會自己慢慢轉回前進方向，單手也好操作。

## 一場比賽的流程

| 回合 | 人數 | 關卡（每場隨機） | 晉級條件 |
|---|---|---|---|
| 第 1 回合 | 30 | 競速：大門衝衝衝／珍奶大滾坡 | 前 20 名過線 |
| 第 2 回合 | 20 | 另一個競速關，或水果配對 | 競速取前 12 名；水果配對淘汰到剩 12 人 |
| 第 3 回合 | 約 12 | 生存：跳跳圈或水果配對 | 淘汰到剩一半，或撐到時間結束 |
| 決賽 | 剩下的人 | 蜂巢崩落／跳跳圈決戰 | 最後一個站著的贏得皇冠 |

被淘汰後可以選擇「繼續觀戰」看完整場，或直接回大廳。

## 關卡

| 關卡 | 類型 | 玩法 |
|---|---|---|
| 大門衝衝衝 | 競速 | 跳過低空旋轉棒 → 撞開三排門（有些是撞不開的假門）→ 擺錘吊橋 → 旋轉圓盤 → 終點 |
| 珍奶大滾坡 | 競速 | 往上爬坡，巨大珍珠從坡頂滾下；中段有十字攪拌棒，後段有往回推的輸送帶 |
| 水果配對 | 生存 | 記住 16 塊地板上的水果，大螢幕出現哪種水果就站上去，其他地板會掉下去 |
| 跳跳圈 | 生存 | 低的旋轉棒要跳過，高的旋轉棒別跳進去，越來越快，撐 70 秒 |
| 蜂巢崩落 | 決賽 | 三層六角形地板，一踩就會掉，最後一個沒掉下去的贏 |
| 跳跳圈決戰 | 決賽 | 跳跳圈加強版，腳下的圓盤會一塊塊掉落 |

競速關掉下去會回到最近的存檔點；生存關和決賽掉下去就淘汰。每一關也都能在「練習關卡」單獨玩，不影響戰績。

## 豆幣與造型

- 每場比賽依撐過的回合發豆幣：參加 5、過第 1 回合 +10、過第 2 回合 +15、過第 3 回合 +20，奪冠再 +100。
- 在「造型」裡可以換顏色、花紋、花紋色和帽子（共 14 款，包含斗笠、礦工帽、安全帽、珍奶杯、旺來頭等台灣味造型），部分需要用豆幣購買。
- 「冠軍皇冠」帽子和「金牌」顏色要拿到第一頂皇冠才會解鎖。
- 進度存在這台裝置瀏覽器的 localStorage（白話：瀏覽器替網站保存資料的小空間）。無痕模式或清除網站資料後，進度會消失。

## 設定

音樂、音效音量；畫質（自動／省電／標準／高）；鏡頭靈敏度與上下反轉；手機震動回饋；顯示每秒格數（FPS，白話：畫面每秒更新幾次，越高越順）。

「自動」畫質在手機上用標準畫質，在電腦上開啟即時陰影；遊戲中如果畫面太卡，會自動降低解析度。

## 檔案

| 路徑 | 說明 |
|---|---|
| `index.html` | **可直接遊玩的成品**（由 `src/` 打包產生，請勿直接修改） |
| `manifest.webmanifest`、`*.png` | 加到手機主畫面用的設定檔與圖示（`tools/icons.mjs` 產生） |
| `src/` | 原始碼：物理、角色、電腦對手 AI、關卡、畫面、音效、介面 |
| `src/levels/` | 六個關卡與大廳場景 |
| `src/template.html` | 網頁外框與介面樣式 |
| `build.mjs` | 打包腳本：把 `src/` 合併成單一 `index.html` |
| `tools/sim.mjs` | 平衡測試：不開瀏覽器，讓電腦對手跑完整關卡並統計結果 |
| `tools/shot.mjs` | 瀏覽器截圖與流程測試（桌機、手機橫向、手機直向；完整一場比賽、觀戰、奪冠） |

## 修改與重新打包（開發者用）

需要 Node.js（白話：在電腦上執行 JavaScript 的工具）。

```bash
cd bean-rush
npm install          # 安裝 three.js 與 esbuild（打包工具）
npm run build        # 重新產生 index.html
npm run sim -- gate 3 30   # 平衡測試：關卡代號、場數、人數
```

關卡代號：`gate`（大門衝衝衝）、`boba`（珍奶大滾坡）、`fruit`（水果配對）、`ring`（跳跳圈）、`hex`（蜂巢崩落）、`ringFinal`（跳跳圈決戰）。

物理和遊戲規則跟畫面是分開的，所以平衡測試可以在沒有瀏覽器的環境下，用 29 個電腦對手實際跑完關卡，檢查完成時間、掉落次數和淘汰節奏。

測試用網址參數（一般遊玩用不到）：

| 參數 | 用途 |
|---|---|
| `?auto=1` | 讓電腦接手操作你的豆豆，用來無人值守地跑完整場比賽 |
| `?speed=4` | 比賽以 4 倍速進行（可設 0.25～8） |
